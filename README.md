# GHOST — In The Machine

A heavy-animated React landing page. Dark terminal aesthetic, matrix rain,
glitch typography, magnetic buttons, 3D tilt cards and a live fake terminal.

Built with React + Vite + Framer Motion. Deployed automatically to GitHub Pages
on every push to `main`.

**Live:** https://ghostusm-cmd.github.io/ghost-landing/

> Building in the dark, shipping in silence.
